# PVArr 0.14.1

Everything in [0.14.0](v0.14.0.md), plus two fixes:

- **College games get the right league.** A game added from the Events tab between two schools
  that play several sports could be filed under the wrong one (a basketball game as NCAAF). PVArr
  now reads "NCAAB", "CBB" and "NCAA basketball" as men's basketball, takes a league or sport word
  from the event page's address when the page's label names none, and never lets a hint pick a
  league one of the teams does not play in.
- **More player pages resolve.** A player that passes its playlist address through base64 as a
  protocol-relative link (`//host/...`) is now decoded like one starting with `http`.

**Upgrading:** `docker compose pull && docker compose up -d`, ideally while nothing is recording.
No settings or API changes.
