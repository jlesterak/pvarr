# PVArr 0.15.1

Everything in [0.15.0](v0.15.0.md), plus a clearer picture of your backups and your connection:

- **Real sources, not just links.** Several links on an event page are often the same feed behind
  different addresses, and they all die together. The card now counts the real sources and turns
  amber when every backup is the same feed as the one you're recording.
- **Backups are checked while you record.** Every 90 s PVArr checks each backup (just the page and
  playlist, no video) and shows a green or red dot on it. When the recording has to fail over, it goes
  to a backup that answered instead of trying a dead one first.
- **Stream rate and a "losing segments" alert.** The card shows how much bandwidth the stream needs.
  If segments start going missing (3 or more within 5 minutes), PVArr sends one notification naming
  that rate, so you know to check what else is using your connection.

**Upgrading:** `docker compose pull && docker compose up -d`, ideally while nothing is recording.
No settings change. The backup checks add a few small web requests a minute per recording.
