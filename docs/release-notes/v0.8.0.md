# PVArr v0.8.0

## New

- **Schedule from an event page.** Give the form an event page together with Start at and End at; at the start time PVArr checks the page and records the first three working streams. See [Event pages and scheduling](../event-pages.md#scheduling-a-recording).
- **Started schedules clear at once.** A scheduled job leaves the list the moment its recording starts; the recording's own card takes over. Failed and missed jobs stay listed for a day so you can read why.

## Improved

- **Faster failover.** A stalled source is now abandoned in about 20 seconds.
- **FlareSolverr timeout is configurable** with `PVARR_FLARESOLVERR_TIMEOUT` (default 120 s, bounded to 10-300), and the messages for a slow or failed solve are clearer. See [FlareSolverr](../flaresolverr.md).
- **`TZ` in the compose file.** Set it in `.env` so recording filenames are dated in your local time rather than UTC.
- **Pinned proxy dependency.** The optional hls-restream-proxy is built from a fixed version instead of whatever is newest, so image rebuilds are repeatable.
