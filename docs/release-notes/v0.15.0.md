# PVArr 0.15.0

Everything in [0.14.2](v0.14.2.md), plus:

- **Wrong Game button.** Sometimes a link labelled as your game plays a different one, and
  often several links on an event page are the same feed behind different addresses, so
  switching to a "backup" lands on the same wrong game. Press **Wrong Game** on the recording
  card: PVArr leaves the stream now and won't use it again in that recording, whichever link
  it turns up behind. Its sources show "wrong game" on their badge, the event-page re-check
  looks for replacements but never puts it back, and the mark survives a restart. It also
  works on a recording with a single link (it keeps retrying until its end time, recording
  nothing rather than the wrong game).
  Scripts can do the same with `POST /api/recordings/{id}/failover` and `wrong_game=true`.

**Upgrading:** `docker compose pull && docker compose up -d`, ideally while nothing is recording.
No settings change.
