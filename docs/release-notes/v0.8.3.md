# PVArr 0.8.3

Everything in [0.8.2](v0.8.2.md), plus:

- **Recordings with an end time no longer stop early when a stream ends itself.** A flaky upstream
  can make FFmpeg finish as if the broadcast were over; PVArr took that at its word and closed the
  recording, even hours before **End at**. Before the end time this now counts as a dropped stream
  and PVArr fails over to the next candidate, as it does for a freeze. Recordings with no end time
  behave as before.

**Upgrading:** `docker compose pull && docker compose up -d`, ideally while nothing is recording.
No settings change.
