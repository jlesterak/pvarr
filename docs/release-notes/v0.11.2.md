# PVArr 0.11.2

Everything in [0.11.1](v0.11.1.md), plus three fixes and a new look.

- **Episode titles in Plex.** With the recommended Plex setup (TV Shows library, Personal Media Shows
  agent) organised recordings showed as "Episode 1" or a date, because that agent reads the title
  only from inside the file. Each recording now carries `<Team A> vs <Team B>` as its title, and
  commercial-detection chapters no longer wipe it.
- **Sources blocked by your DNS.** A host your Pi-hole or AdGuard answers with `0.0.0.0` is now
  reported as *blocked by DNS* and failed over at once, instead of being retried and shown as a
  private address. If your blocklist covers stream hosts, give PVArr its own DNS (see
  [troubleshooting](../troubleshooting.md)).
- **Fallback proxy host learning** now refuses `localhost`, alternate spellings of local addresses
  and LAN hostnames, not only private IP literals.
- **New theme:** warm wood, parchment and brass instead of blue.

**Upgrading:** `docker compose pull && docker compose up -d`, ideally while nothing is recording.
No settings change. Recordings organised before 0.11.2 have no title tag; Plex keeps showing them
as "Episode N" unless you add one (`ffmpeg -i in.mp4 -map 0 -c copy -metadata title="A vs B" out.mp4`).
If your library was ever matched with an online agent, unmatch each sport's show, refresh its metadata,
and edit its name back to the folder name (unmatching keeps the old one).
