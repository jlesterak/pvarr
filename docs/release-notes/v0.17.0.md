# PVArr 0.17.0

Everything in [0.16.0](v0.16.0.md), plus:

- **Reads segments packed inside WebP images.** Some feeds serve each video segment as a WebP file:
  a short image header followed by ordinary MPEG-TS. PVArr recognises them on the first segment
  ("image-wrapped video") and its relay cuts the header off before FFmpeg sees it. No image decode is
  needed, so unlike PNG-wrapped feeds this costs no extra CPU. On the game where it was found, the
  WebP feed was the only one on offer that didn't freeze.
- **The event-page re-check names the links it couldn't use.** When sources die partway through a
  recording and PVArr re-checks the event page, the card log now lists the links that gave no
  playlist (usually players that build their URL in JavaScript), up to 20, so you can try them by
  hand instead of only seeing "9 unresolved".

**Upgrading:** `docker compose pull && docker compose up -d`, ideally while nothing is recording.
No settings change.
