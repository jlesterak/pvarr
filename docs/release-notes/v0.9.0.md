# PVArr 0.9.0

Everything in [0.8.3](v0.8.3.md), plus:

- **Ad Stats tab.** With commercial detection on (`PVARR_COMSKIP=1`), each finished recording
  adds a row to `/config/comskip-stats.csv`: its length, the time comskip marked as ads, and
  the share. A new dashboard tab shows the overall share, a bar per league and one row per
  recording, so you can compare leagues, or regular season against playoffs. The numbers are
  comskip's estimate: a broadcast that drops its corner logo for long stretches will read low.
  Served read-only by `GET /api/stats/ads`.

**Upgrading:** `docker compose pull && docker compose up -d`, ideally while nothing is recording.
No settings change; the tab stays empty until comskip is on.
