# PVArr 0.12.0

Everything in [0.11.2](v0.11.2.md), plus:

- **How many real sources a page has.** An event page often lists a dozen links that all play the
  same feed through different sites. **Find 3 streams** now counts every link by what it turned out
  to be, e.g. *"12 links: 4 working from 1 real source (A ×4), 2 not video, 6 unresolved"*, and
  gives each link a letter shared by its mirrors. A re-check logs the same for the rest of the page,
  so you can tell when it simply has no other feed. The recording card shows how many real sources
  stand behind its candidates (amber when there is only one) and a letter on each candidate.
- **Streams that are not video are never picked.** A link whose playlist works but whose segments
  are something else (images, HTML) used to count as working and could become the primary; FFmpeg
  then found nothing in it on every failover. It is now listed as *not video* and left out.
- **Segments packed at a byte range** inside a larger file are measured at their range, so those
  sources are ranked by real quality instead of being picked unmeasured.

**Upgrading:** `docker compose pull && docker compose up -d`, ideally while nothing is recording.
No settings change. The API adds fields (`summary`, and `status`/`source` per link in
`/api/aggregate`; `source`, `distinct_sources`, `unknown_sources` in `/api/status`); nothing is removed.
