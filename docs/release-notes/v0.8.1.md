# PVArr 0.8.1

First public release. Everything in [0.8.0](v0.8.0.md), plus:

- **Local-time filenames.** `docker-compose.yml` now passes `TZ` through. Set it to your timezone
  (for example `TZ=America/Denver`) so an evening recording is dated the day it aired, not the next
  day in UTC.
- **Pinned dependency.** The optional hls-restream-proxy is pinned to a known commit, and a failed
  download now fails the build instead of shipping an image without it.
- **Project files.** Issue and pull request templates, a security policy, and a shorter README with
  the reference material in `docs/`.

**Upgrading:** add `TZ` to your compose file's environment (see the example in `docker-compose.yml`),
then `docker compose pull && docker compose up -d`. Nothing else changes.
