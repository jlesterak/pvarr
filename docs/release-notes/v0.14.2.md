# PVArr 0.14.2

Everything in [0.14.1](v0.14.1.md), plus five fixes for live recordings:

- **Working recordings aren't given up on.** When the candidate list wrapped, a lap in which
  sources had just recorded for minutes still counted as fruitless, which could end a working
  recording early. Only laps that got no data count now.
- **Freeze messages blame the right thing.** "FFmpeg said" now shows FFmpeg output from the last
  minute, not a start-up message from hours earlier; an older line is labelled with its age.
- **Fresh links are tested before they replace a source.** The event-page re-check probes each
  new link first, so a page with nothing playable no longer pushes out a source that was working.
- **Chapter remux is safer.** The remuxed file keeps the original's permissions, and the remux is
  skipped with a warning unless there is the file's size plus 5 GB free, so it can't fill the disk
  under a recording that is still running.
- **Faster, gentler restarts.** Sessions left over from before a restart are finished in the
  background after the server is up (it no longer waits minutes on commercial detection), and a
  clean restart (an image update, Docker restarting) no longer uses up a recording's resume
  attempts.

**Upgrading:** `docker compose pull && docker compose up -d`, ideally while nothing is recording.
No settings or API changes.
