# PVArr 0.8.2

Everything in [0.8.1](v0.8.1.md), plus:

- **Better commercial detection out of the box.** When you have not supplied your own `comskip.ini`,
  the default PVArr writes now adds `detect_method=111` and `logo_threshold=0.75`. On four broadcast
  recordings from four networks, scored against hand-checked break lists, the share of ad time caught
  rose by 0-10 points per network (best case 85% -> 95%) while precision stayed around 97-99%.
  Details and caveats in [docs/comskip.md](../comskip.md).

**Upgrading:** `docker compose pull && docker compose up -d`. Only affects you if `PVARR_COMSKIP=1`;
a `comskip.ini` you set with `PVARR_COMSKIP_INI` still takes priority.
