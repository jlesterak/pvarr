# PVArr 0.20.3

Everything in [0.20.2](v0.20.2.md), plus one dashboard fix.

- **The dashboard no longer says "System Idle" while PVArr is still working.** After a recording ends, or
  after a restart picks up one that was cut short, PVArr can spend up to an hour remuxing it, moving it to
  the library and scanning it for commercials. The header now reads "Processing N recording(s)" (amber)
  during that time, and the Live Recorders tab lists each file with its step and how long it has been at
  it. `/api/status` carries the same list as `post_processing`.

**Upgrading:** nothing to change.
