# PVArr 0.11.1

Everything in [0.11.0](v0.11.0.md), plus a new option and two fixes for streams that were recorded as an empty file.

- **Organise finished recordings** (`PVARR_LIBRARY_DIR`, off by default). After the remux, a recording moves to
  `<dir>/<Sport>/Season <year>/<Sport> - S<year>E<NN> - <A> vs <B>.mp4`, a layout Plex reads as a show per sport.
  The folder must be inside the recordings volume; anything else is refused, never copied.

The fixes:

- **Segments served under a non-video extension.** Some live sources list real video segments
  under `.image` URLs. PVArr's direct connection refused them, so a recording stayed at 0 bytes
  while it cycled through every candidate. They are now accepted.
- **The fallback proxy works for those sources too.** It refused segments hosted on a different
  domain than the playlist, and ignored byte ranges, so it could not rescue a stream either.
  Both are fixed.

**Upgrading:** `docker compose pull && docker compose up -d`, ideally while nothing is recording.
No settings change.
